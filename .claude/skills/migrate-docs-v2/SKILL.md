---
name: migrate-docs-v2
description: >
  Migrate a consumer repository's AsciiDoc include paths from
  gesinn-it-docs-master-pub v1 (flat snippet names) to v2 (scoped
  subdirectory structure). Use when updating the submodule pointer to v2
  causes broken include:: paths in the consumer repository's source files.
  Searches all *.adoc source files for old include paths, replaces them with
  v2 equivalents, and validates that no old paths remain.
compatibility: >
  Requires gesinn-it-docs-master-pub submodule updated to v2.
  Consumer repo must have source .adoc files (not only generated output).
---

## Context

The submodule at `docs/gesinn-it-docs-master-pub` has been updated to v2,
which reorganises snippets from flat names into scoped subdirectories.

**Old pattern:** `snippets/{scope}/coding-conventions-{lang}.adoc`
**New pattern:** `snippets/{scope}/conventions/{lang}.adoc`

Load `references/01-path-mapping.md` before making any changes — it contains
the complete old-to-new substitution table.

## Step 1: Locate all affected source files

Search for .adoc files that contain `gesinn-it-docs-master-pub` include paths
or relative include paths into the submodule directory:

```bash
grep -rl "gesinn-it-docs-master-pub/snippets" . --include="*.adoc" 2>/dev/null
grep -rl "snippets/mediawiki\|snippets/universal\|snippets/nodejs\|snippets/ansible" docs/ --include="*.adoc" 2>/dev/null
```

Also check for includes that use the `{project_type}` variable expansion:

```bash
grep -rl "{project_type}/" . --include="*.adoc" 2>/dev/null
```

**Do not modify generated files** — skip `README.adoc` and `AGENTS.md` (they
are auto-generated and will be regenerated by CI after source files are fixed).

## Step 2: Load the path mapping

Read `references/01-path-mapping.md` for the complete substitution table before
making any changes.

## Step 3: Apply substitutions

For each source file identified in Step 1:

1. Read the full file content
2. Apply each substitution from the path mapping table
3. Show the diff before writing
4. Write the updated file

Use the sed patterns from `references/02-regex-patterns.md` for mechanical
substitutions. The patterns handle both:
- Consumer-repo form: `docs/gesinn-it-docs-master-pub/snippets/...`
- Submodule-internal form: `snippets/...` (for files inside the submodule)

Pay special attention to files that used the `{project_type}` variable — these
must be expanded to explicit paths (e.g. `mediawiki/conventions/general.adoc`).

## Step 4: Validate

Run the validation checks from `references/03-validation.md` to confirm that
no old-format paths remain in any source file.

Expected result: zero matches for all grep patterns listed in the validation
reference. If any matches remain, return to Step 3 and apply the missing
substitutions.

## Step 5: Commit

Use the commit template from `references/04-commit-procedure.md`.

Stage only the source files that were modified (not generated output files).
