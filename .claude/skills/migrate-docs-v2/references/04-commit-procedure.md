# Commit Procedure

After all substitutions have been applied and validation passes:

## Stage only source files

Stage each modified source file explicitly. Do **not** stage:
- `README.adoc` (auto-generated — will be regenerated by CI)
- `AGENTS.md` (auto-generated — will be regenerated by CI)

```bash
git add <each-modified-source-file.adoc>
```

Verify the staged diff looks correct:

```bash
git diff --staged
```

## Commit message template

```
chore(docs): migrate to gesinn-it-docs-master-pub v2 snippet paths

Update all AsciiDoc include:: paths to the v2 scoped subdirectory structure.

Old: snippets/{scope}/coding-conventions-*.adoc, ci-*.adoc
New: snippets/{scope}/conventions/*.adoc, execution/*.adoc, procedures/*.adoc
```

## Checklist before pushing

- [ ] Validation grep returns zero matches (see `03-validation.md`)
- [ ] No generated files (`README.adoc`, `AGENTS.md`) are staged
- [ ] Submodule pointer is updated to v2 tag (run `git submodule update --remote` or set manually)
- [ ] CI passes after push (asciidoctor-reducer must resolve all includes)
